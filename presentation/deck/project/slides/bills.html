On these small agents fleetopt cost about fifty times what the agents did. It pays where an agent spends real money.

There are two bills and they never mix. The first is the team's own agent: when fleetopt measures it, the agent makes its usual model calls on its own key. On three test agents using small, cheap models that came to thirty-six cents in total across thirteen runs, and it is capped at two dollars a run by default. The second is fleetopt's own work: the AI session that does the reviewing and changing, and the separate reader that checks answers. That came to about eighteen dollars across the same thirteen runs: roughly a dollar and a half for a design review, under a dollar for a cost review, and between fifty cents and three dollars thirty for a run that changes code. Be direct about the ratio: on agents this small, fleetopt costs far more than the agent it is measuring. It earns its cost on an agent that spends real money every day, which is why the next test is a production agent.
