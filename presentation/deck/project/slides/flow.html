This is what happens when a developer runs it. fleetopt starts the team's agent in the team's own setup and measures it as it is: cost, tokens, time and the answers it gives. Then the expert looks for what it is there to find. With review it stops there and reports; nothing is changed and a person decides. With apply it goes on alone: it makes the changes on a branch of its own, proves them against the gate, keeps what passes, and looks again until nothing more is kept. The report says what was kept, what was refused and why. A team needs four things ready: the project in git, an agent that runs, something to check it against, and model calls made through LangChain. If the project has nothing to check against, fleetopt can write requests itself and the report says so; it may put one question to the developer before it starts measuring.
