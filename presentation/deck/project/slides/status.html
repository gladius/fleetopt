It needs thorough testing on real agents before any wider use.

Close on this. It is work in progress. So far it has run on three public multi-agent projects: it found five real defects and kept two changes that passed the gate, one of them a proven saving of 42% in cost. It has not yet been proven on a production agent. The biggest open concern is test material: public agents are small, run on cheap models, and rarely come with a golden dataset or an eval suite, so they cannot show what this is worth. The others are the width of the evidence, which is only as wide as the handful of requests it runs; its reach, which today is LangGraph in Python with model calls through LangChain; and setup on a production machine. The ask is concrete: two or three teams with a production agent that spends real money and has something to check it against, and a developer at the terminal for the first runs.
