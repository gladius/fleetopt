fleetopt is an agent built on the Claude Agent SDK. Each run is one SDK session, and the SDK drives the Claude Code program, which either ships inside the SDK package or is installed on the machine. It signs in the way Claude Code already does there: the company's gateway settings or a Claude login. fleetopt holds no key of its own. From the machine's Claude setup it takes only how to sign in, plus any policy the company manages. It deliberately loads nothing else: not the developer's plugins, skills, hooks or MCP servers, not the project's own .claude folder, and it keeps no memory between runs. That way every run on every machine behaves the same, and another team's repository cannot instruct it. The models are named sonnet, opus and haiku, and resolve to whatever your setup provides.
