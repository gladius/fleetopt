In the code · fleetopt/

cli.py the command · config.py signs in the way Claude Code does on the machine; no key of its own

the session · and its experts

  • session.pyThe one Claude session: guards, model, the run
  • tools.pyThe 8 tools every expert uses, with the limits and git inside them
  • expert.pyLoads an expert from a folder; holds the rules a change must meet
  • experts/Prose only. The shared guide, and one folder an expert: cost/, design/

probe/ · runs and records

  • driver.pyStarts the team's graph in their own Python, with their env files and folder
  • hooks/Records every model call, without editing their code
  • runner.pyOne run, stopped if it never ends or runs away
  • store.pyThe records, in SQLite

evidence/ · what counts

  • measure.py3 runs, medians, only a change past the noise counts
  • pricing.pyTokens to dollars, per model and provider
  • judge.pyThe separate reader: did anything break
  • shape.pyWhat the graph declared against what it did, for the design expert
  1. CheckReads the project, finds what to check against, and how the team runs it; start tries one request
  2. Baselinerun evals on the original, then measure: 3 runs, every call recorded
  3. Findquery the recorded calls and read the code, with the skills
  4. ChangeEach fix its own save, a named commit on fleetopt's branch
  5. ProveOne measure and evals for all; keep only if cheaper and nothing broke, else undo and split
  6. ReportIts account, and a summary computed by code; the team's copy is back as it was

What keeps it safe

  • Never touches a team's live code
  • Kept only if cheaper and the team's own checks still pass
  • A person decides what is merged
